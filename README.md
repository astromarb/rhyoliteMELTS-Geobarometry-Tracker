# rhyoliteMELTS-Geobarometry-Tracker

A fast, easy-to-use single-file HTML app for tracking rhyolite-MELTS simulations and visualizing outputs.

#### How to use

Open `index.html` in a browser.

## Data Management (import/export)

All data is stored locally in the browser. Use the app's export/import controls to back up and restore project JSON.
